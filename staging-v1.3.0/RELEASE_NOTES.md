## 🚀 主要更新特性

### 1. 🔑 一机一码数字签名授权系统 (Ed25519)
* **硬件级指纹绑定**：dao-cli 在首次启动时，会自动跨平台安全提取本机的物理网卡 MAC、主板序列号与硬盘串信息，混合 SHA256 哈希后生成您本设备的唯一专属 **Machine ID（机器特征码，如 `M-8F3C-2A1B-E9D0`）**。
* **高强度非对称激活**：我们引入了椭圆曲线数字签名算法 **Ed25519**。激活码是由开发者专属私钥对您的机器特征码签名派生的，拷贝他人的激活码或在别处试图破解公钥，均 100% 无法激活，完美实现“一机一码”。
* **极简极美引导交互**：在首次 Onboarding 交互的第二步（Welcome 之后，Language 之前），会呈现优雅的授权激活屏幕。支持剪贴板一键粘贴；**若无解锁码，直接按回车（Enter）即可瞬间跳过，无感切入「标准受限版」**，友好度拉满！
* **新 Slash 斜杠命令**：支持 `/license`、`/shouquan`、`/激活` 命令。您可以在任何时候查看机器特征码、执行解锁码激活或清空激活状态。

### 2. 🛡️ 高危安全网关拦截过滤 (ExecPolicy Compliance Sandbox)
为了帮助软件拥有者规避法律纠纷，防范不法分子利用 dao-cli 做恶意违规用途：
* **标准受限版锁定高危词**：对于未激活的「标准版」，底层安全执行引擎在准备执行或 AI 试图调用工具时，将进行精确的分词审计扫描。
* **熔断拦截范围**：一旦检测到命令中包含渗透漏洞高危词（`nmap`/`sqlmap`/`gobuster`/`dirb`/`hydra`/`msfconsole`/`nc`/`netcat`/`masscan`/`nikto`/`burpsuite`）、爬虫高危词（`scrapy`/`pyppeteer`）或逆向破译词（`frida`/`apktool`/`dex2jar`），网关将瞬间强力阻断并安全熔断，弹窗发出红色合规预警。

### 3. 👑 开发者“刀仔”专属开发特权锁
* **无缝开发体验**：内置了 `DAO_DEV_KEY` 编译环境变量。只要是刀仔本人在编译时注入了专属开发密钥，或者在刀仔的专属开发机上启动，程序将通过数字特征判断并强制判定为“刀仔开发特权版”，自动跳过激活并无限制解锁全部高危模块，方便开发和持续升级！
* **防篡改防爆破**：公钥数据通过高强度的二进制异或（XOR 0x66）算法混淆存储，有效阻止了试图通过 Hex 工具直接搜索替换公钥的恶意篡改行为。

## 🛠️ 普通用户（小白级）极简安装升级教程

为了立即升级体验本次 v1.3.0 精心设计的合规安全商业版，请按照以下简单步骤操作：

### 第一步：覆盖原有的老版本程序
1. 打开您的文件资源管理器，并跳转到您的 dao-cli 安装目录：
   > 提示：一般是在您的 `C:\Users\您的电脑用户名\AppData\Local\Programs\dao-cli\` 目录下，或者您的环境变量 PATH 指向的包含 `dao.exe` 的目录。
2. 将在此发布包中编译生成的 **`dao.exe`** 和 **`dao-cli.exe`** 覆盖替换原先的两个同名老文件。

### 第二步：首次启动与机器码获取
1. 在 Windows 系统的任何地方按下键盘的 `Win + R` 键，在弹出的“运行”框中输入 `cmd` 或 `powershell` 并点确定，打开命令终端。
2. 直接在终端输入 `dao` 并按下回车（Enter）启动软件。
3. 首次进入引导时，您会在第二个页面看到如下提示：
   ```text
   设备机器码 (Machine ID): M-ABCD-1234-EFGH
   ```
4. 如果您是普通用户，可以直接按 **键盘上的回车键 (Enter)** 跳过，立刻可以开开心心编写标准代码了！
5. 如果您是高级付费用户，可以用鼠标直接选中屏幕上这行机器码复制，发给开发者“刀仔”。

### 第三步：输入激活码解锁高级版
1. 收到刀仔提供给您的专属解锁码后，如果您在刚才的 Onboarding 页面中，可直接按 `Ctrl + V` 粘贴激活码并点回车激活。
2. 如果您之前已经回车跳过了，随时可以在 dao-cli 的普通对话输入框中，输入 `/license` 或是 `/激活` 命令回车，系统会展示您的机器码。
3. 输入 `/license activate 您的解锁码` 并按回车，您将看到系统弹出绿色通知：
   > 🎉 **系统已成功授权激活！高级高危安全模块已全面无锁放开。**
