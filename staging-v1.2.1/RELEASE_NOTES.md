# DAO-CLI v1.2.1 临时测试版 (Staging-v1.2.1)

> 快速迭代：完美支持方向键向上翻看历史命令，并在输入框中随意编辑后发送。

## 新增与改进

* **按键盘向上键默认翻看命令历史与随意编辑**
  * **设计初衷**：彻底解决此前版本在 Windows 终端（由于默认在 Windows 下开启了 `composer_arrows_scroll` 属性）下按 `↑` 键引发的“意外滚动 transcript 屏幕而不是翻看命令”这一反直觉体验。
  * **改进细节**：将单行输入框中 plain Up/Down 滚动 transcript 的策略改为默认关闭。现在按 `↑` 将完美且直观地为您**调出并翻看上一条发送过的历史命令**。
  * **可编辑性**：当命令历史被翻出并填入输入框后，您可以**完美对其进行任意的增删改编辑**，再次按回车键（Enter）即可快速重复发送，体验极佳。
  * **备用控制**：若需要滚动聊天记录，依然可以通过鼠标滚轮，或者使用 `Alt + Up / Down` 等复合修饰键来进行屏幕滚动。
